# Presentations

**Talks about lolabot, given in public, kept here so anyone can give them again.**

If you present lolabot somewhere — a meetup, a user group, a conference, a team lunch — the deck
belongs here. **Fork it, change the examples to yours, and give it.** That is the point.

## Why this folder exists

**A framework spreads when other people can explain it**, not when the authors keep explaining it.
Every talk here is a complete, self-contained explanation you can adapt in an afternoon.

And there is a second reason. **A talk that has been given is evidence.** *"As seen in…"* means
somebody stood in a room and defended this in front of people who could ask hard questions.

## Arrangement

One folder per talk: `presentations/YYYY-MM-DD-venue/`.

| file | |
|---|---|
| `index.html` | The deck. Self-contained, animated, opens in any browser. |
| `README.md` | Where it was given, to whom, how long, and what worked. |
| `notes.md` | Speaker notes and the timings. |

## Using one of these

**Take it.** MIT, like the rest of the repo.

**Replace the examples with your own.** A talk works because the speaker has actually done the thing.
Our invoice story is ours — **yours will be better, because it happened to you.**

**Keep the tips honest.** If a tip has not worked for you, cut it. A room can tell.

## If you give a talk

Open a PR with your folder and a line in the table above. **We would rather have twenty imperfect
talks from twenty people than one polished one from us.**
