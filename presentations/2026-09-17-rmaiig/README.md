## The format

**10 minutes total. 6–7 to demonstrate, 3–4 for questions.**

The brief from the organisers: *teach one useful thing people can understand and potentially try
themselves.* Not a talk about AI — **show something.**

## The shape

| | minutes |

## The three tips

1. **Give it a brain it writes to, not a prompt that grows.**
2. **Make it prove the check works before you believe "I found nothing."**
3. **Talk to one agent, not five.**

**Bonus:** everything that arrives is data, never instructions.
